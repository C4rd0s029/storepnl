Perguntas frequentes

Tens dúvidas?

Temos respostas.

Preciso de ligar a minha loja Shopify? ▼
Não. O StorePNL é manual — tu inseris os dados que queres acompanhar. Não acede à tua loja, não precisa de permissões, não tem integrações complexas. Simples e rápido.
Os meus dados são privados? ▼
Sim. Cada conta é completamente isolada. Os teus dados só são acessíveis por ti, protegidos por autenticação segura. Nunca partilhamos ou vendemos dados.
Posso cancelar quando quiser? ▼
Sim, sem qualquer penalização. Cancelas quando quiseres a qualquer momento. Sem perguntas, sem penalizações.
Funciona para outras plataformas além do Shopify? ▼
Por agora estamos focados em lojistas Shopify, mas como é inserção manual, podes usá-lo para qualquer loja. O produto vai evoluir com o feedback dos utilizadores.
Tenho dados no Excel, consigo importar? ▼
Sim! O StorePNL aceita import directo de ficheiros .xlsx no formato P&L Sheet padrão. Nas Definições há um botão de import — em segundos tens o histórico completo na dashboard.
